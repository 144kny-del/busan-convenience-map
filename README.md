# 부산 편의지도

현재 위치를 기준으로 부산의 장소와 편의시설을 검색하고 지도에서 확인하는 프로토타입입니다.

## 주요 기능

- 브라우저 위치 정보로 현재 위치 표시
- 카카오 장소 검색 API를 이용한 주변 장소 검색
- 1km~5km 검색 반경 선택
- 검색 결과 전체를 지도 마커로 표시
- 장소 상세 정보와 카카오맵 길찾기 연결

## 실행 방법

1. [Node.js](https://nodejs.org/) 18 이상을 설치합니다.
2. 저장소 폴더에서 다음 명령을 실행합니다.

```bash
npm start
```

3. 브라우저에서 <http://127.0.0.1:3000/>을 엽니다.
4. 앱에서 카카오 REST API 키를 입력합니다.

Windows에서는 `부산편의지도-실행.vbs`를 더블클릭해도 됩니다.

## 카카오 API 설정

카카오 Developers에서 애플리케이션을 만든 뒤 **REST API 키**를 사용합니다.
키는 서버 메모리에만 저장되며 저장소나 브라우저 저장소에는 저장하지 않습니다.

> API 키, 클라이언트 시크릿 등의 인증 정보는 GitHub에 올리지 마세요.

## 참고

- 이 프로젝트는 로컬 Node.js 서버가 필요하므로 GitHub Pages에 정적 파일만 올려서는 장소 검색이 작동하지 않습니다.
- Render 같은 Node.js 호스팅에서는 빌드 명령 없이 `npm start`로 실행할 수 있습니다.
- 위치 정보는 브라우저 권한 허용이 필요합니다.
- 지도 데이터는 OpenStreetMap, 장소 검색은 카카오 Local API를 사용합니다.
